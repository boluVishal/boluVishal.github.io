# boluVishal.github.io

A landing page built for the CodeChef DSACP (Data Structures & Algorithms Certification Program) — India's DSA certification with three levels: Foundation, Advanced, and Expert.

## What's on the page

- Header with CodeChef branding and contact info
- Exam date and registration deadline
- Overview of what the certification covers
- The three certification levels with brief descriptions
- Pricing (with a discounted period)
- Testimonials section
- Free resources and mock test links

## Stack

Plain HTML and CSS — no frameworks, no build step. Images were exported from a design tool (Avocode, based on the SVG metadata in the HTML).

## Running it

Just open `index.html` in a browser. Everything is local — fonts, stylesheets, and images are all relative paths.

```
open index.html
```

Note: the page references some image paths that may need to stay flat (no subdirectories) to load correctly.
